# Figma 배너 참고 원본

사용자가 제공한 SVG를 수정 없이 보관한다. 원본의 캔버스는 모두 1440 × 288이다.

| 파일 | 구성 | 확인된 색상·요소 |
| --- | --- | --- |
| [매일 메일](../assets/references/maeil-mail.svg) | 왼쪽 로고 + 큰 제목 + 아래 부제·구분선 | 배경 `#2C2C2C`, 흰 글자 |
| [수능형 문제 풀이 모델](../assets/references/exam-model.svg) | 로고 없이 넓은 제목 + 중앙 부제·구분선 | 흰 배경, 주황 글자 |
| [Zotero](../assets/references/zotero-preview-resizer.svg) | 왼쪽 아이콘 + 한 줄 제목 | 흰 배경, 검은 글자; 아이콘은 SVG 안에 PNG로 내장 |
| [Behind Fitness](../assets/references/behind-fitness.svg) | 왼쪽 로고 + 큰 제목 + 오른쪽 아래 부제 | 배경 `#131623`, 흰 글자, 파란 로고 |

이 파일에는 `text`나 `tspan` 요소가 없고 글자도 path로 변환되어 있다. 원본의 폰트 이름·텍스트 편집 속성은 복원할 수 없다. 글자 모양을 재사용하는 것은 가능하지만 새 프로젝트명으로 바꾸려면 별도의 텍스트 요소가 필요하다. 사용자가 기존 폰트는 **Gmarket Sans**라고 확인했다. 새 템플릿은 이 폰트를 사용하며, 원본별 정확한 굵기와 크기는 별도로 시각 비교한다.

원본은 참고용이며 기존 프로젝트의 공개 자산을 자동으로 교체하지 않는다. 아이콘+제목 형식은 Zotero, 부제가 있는 어두운 형식은 Behind Fitness를 우선 비교한다. 새 SVG는 편집 가능한 원본으로, PNG는 표시 결과를 고정한 산출물로 보관한다.
